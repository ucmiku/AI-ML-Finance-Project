# ERCOT正式训练表变量字典与特征工程说明

## 1. 数据概览

正式数据表为 `data/model_training_table_leakage_safe_v1.csv`，共 **21,666 行、95 列**。其中，**72列为M3正式模型特征**，其余为时间标识、审计字段、实际价格和预测目标。预测目标为 `spread = rt_price - da_price`。

所有天气、负荷、风电和光伏字段按业务确认均为日前10:00前可获得的预测值。实际DA价格和RT价格只保留用于审计，不进入模型。历史Spread变量采用decision-time as-of对齐，不是对交付行简单执行`shift()`。

## 5. 关键口径

`spread_asof_lag24/48/168`以日前决策信息边界为锚点进行精确时间戳匹配；信息边界为交付日前一日本地09:00（不含），最近完整观测小时为08:00。24小时滚动均值和标准差使用边界前24个完整小时。

`heavy_rain_city_count`的阈值仅由2024训练集`precipitation_dfw_mean_mm`的95%分位数确定；`low_wind_city_count`的阈值仅由2024训练集`wind_speed_dfw_mean_ms`的10%分位数确定，并将同一阈值应用于2025和2026。

表构建阶段没有因为Pearson相关性或VIF删除变量，以便树模型和深度学习模型使用完整M3特征集；共线性筛选仅在线性模型管道内部实施。
