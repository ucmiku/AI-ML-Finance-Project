## 2. 策略定义（按复杂度递进）

### 2.1 B1A: Always Short（始终做空）

- **逻辑**: 盲目做空 RT-DA 价差（Signal = -1），押注 RT < DA
- **类型**: 天真策略 / 下限基准
- **预期**: 在 ERCOT 市场 RT 历史平均低于 DA，应有正收益但波动极大
- **信号来源**: 无 — 全时段固定做空

### 2.2 B1B: Random Daily（每日随机）

- **逻辑**: 每天随机选择做多(40%)、做空(40%)或不交易(20%)
- **类型**: 随机策略 / 零预测能力基准
- **预期**: 长期收益接近 0，夏普接近 0
- **信号来源**: 伪随机数生成器 (seed=42)

### 2.3 B2: MA Crossover（双均线交叉）

- **逻辑**: 基于实际价差的短期均线(24h)与长期均线(168h)交叉产生信号
  - 金叉 (MA₂₄ > MA₁₆₈) → 做多 (+1)
  - 死叉 (MA₂₄ < MA₁₆₈) → 做空 (-1)
- **风控**: 最小价差 $5/MWh, 波动率最低 $3/MWh
- **类型**: 经典技术分析策略 / 纯时序基准
- **信号来源**: 实际 RT-DA 价差的滞后值（无 look-ahead bias）

### 2.4 C1-060: B2B Handoff 基准（threshold = 0.60）

- **逻辑**: C1 XGBoost B2B 分类器信号，概率阈值 0.60
  - `p_positive >= 0.60` → DEC（做空价差, Signal = +1）
  - `p_negative >= 0.60` → INC（做多价差, Signal = -1）
- **类型**: 机器学习驱动策略 / C1 模型交付基准
- **信号来源**: C1 B2B 5/20 分类器概率输出

### 2.5 C1-070: B2B 最优阈值（threshold = 0.70）

- **逻辑**: 与 C1-060 完全相同的规则，仅将概率阈值从 0.60 提高至 0.70
- **优化依据**: 网格搜索 0.50–0.80，0.70 在 Sharpe × PnL 上达到最优
- **核心改善**: 过滤 60% 低质量信号，正常天气 PnL 从 -$437 转正为 +$307
- **类型**: 参数优化后的 C1 纯概率策略

### 2.6 C1-EWO: ExtremeWeather_Only 🥇（最终选定策略）

- **逻辑**: C1-070 基础上叠加三重增强:
  1. B2B 概率阈值 0.70（高置信度筛选）
  2. B2A 回归方向确认（predicted_spread 符号与 B2B 信号一致）
  3. **极端天气风险开关** — 仅在 `fixed_extreme_weather_flag=1` 时开仓
- **类型**: ML + 天气条件混合策略 / **最终选定策略**
- **信号来源**: C1 B2B 分类器 + B2A 回归头 + 外部天气标签
